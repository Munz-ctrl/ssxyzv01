# The Sunsex agent: working principles

Draft from Munzir's notes after the first playtest (Nov 12). The Agent Lab session will expand this. PRODUCT.md and the newest brief still win on anything built.

## What it is
- The player is typing to **themselves**. The `[ + ]` is a private journal, not a chat.
- The agent listens from the sidelines and answers somewhere else (the receipt, the vault, the prompt box), never as a chat reply.
- **Complete neutrality.** No judging, no preaching, no cheerleading.
- **Speaks only when necessary.** Silence is a valid response.
- Pulls toward action when action is needed, and rewards illogical, spiritually fulfilling acts just as much as productive ones.
- Tries to read the player's frequency: their current mode and thought pattern. It shows what it learned only through nudges.

## Response types
| Response | When | Player sees |
| --- | --- | --- |
| silence | nothing worth adding | the receipt only |
| +1 cube | a light dump | a short receipt, then a custom nudge in the prompt box |
| +more cubes and extras | a rich dump (new, specific, reflective, plan) | the cube acquisition flow |
| visual change / asset | a space edit or a camera capture | the cube spend flow |
| box drop | an object earned | a box lands to unpack *(next to test)* |
| note | heavy dumps only | a short serious line in the vault |
| mission | a doable next step | a mission card |
| mission chain | a big goal ("get into college") | **looks like normal missions to the player**; code links them and pays a bigger bonus when the goal completes |
| insight | a line about one dump | **under that dump in history**, not in the vault |
| pattern | the same thing across several dumps | vault, **only** when it is consistent and can be said with value |

## Data
All data is valuable for now: throw a net and see what we catch. Raw dumps are kept forever so they can be rescored.

## Nudging
- A fading series of filler questions in the empty prompt box ("wya?", "how you feel?", ...).
- Later: a "mother agent" customizes the rotation per player, based on what it has learned and what is missing.

## Parking lot
- **Agent does a mission step for cubes.** e.g. a "write claude prompt" step in the vault is clickable: spend cubes, the agent writes it, the step is marked done, and the multiplier goes up.
